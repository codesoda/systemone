# Support

Use GitHub issues for reproducible bugs and focused feature requests:

- [Open an issue](https://github.com/codesoda/systemone/issues/new)

Search existing issues first. Include the `s1 --version` output, your
`s1 config show` output (it redacts secrets), the exact command, and the JSON
error record from stderr. Use synthetic request data only. Do not include
credentials, private state, or model files.

The project does not provide a guaranteed response time or private support.
For security vulnerabilities, do not open an issue. Follow the
[security policy](SECURITY.md) instead.

[docs/RELEASE.md](docs/RELEASE.md) lists supported platforms and what each
release does and does not verify.
